# Хранилище хешей файлов (HashStorage DApp)

Децентрализованное приложение для подтверждения факта существования документа без раскрытия его содержимого. Пользователь сохраняет keccak256‑хеш файла в смарт‑контракте, после чего любой желающий может проверить, был ли такой хеш зафиксирован, а также узнать, кем и когда.

Проект выполнен в рамках итоговой работы по дисциплине «Основы технологии блокчейн».

## Технологии

- **Solidity** (0.8.20) – смарт‑контракт
- **Hardhat** – компиляция, деплой, тестирование
- **Next.js, Wagmi, Viem, RainbowKit** – пользовательский интерфейс и интеграция с кошельком
- **MetaMask** – авторизация и подписание транзакций

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/mrmitin78-arch/Final.git
   cd my-dapp
   ```

2. Установите зависимости:
   ```bash
   yarn install
   ```

3. Запустите локальную сеть Hardhat (в отдельном терминале):
   ```bash
   yarn chain
   ```
   Сеть доступна по адресу `http://127.0.0.1:8545`, Chain ID 31337.

4. Выполните деплой контракта:
   ```bash
   yarn deploy
   ```
   После успешного деплоя в консоли появится адрес контракта `HashStorage`.

5. Запустите фронтенд (в другом терминале):
   ```bash
   yarn start
   ```
   Приложение откроется на [http://localhost:3000](http://localhost:3000).

6. Подключите MetaMask:
   - Добавьте сеть с параметрами: RPC URL `http://127.0.0.1:8545`, Chain ID `31337`, символ ETH.
   - Импортируйте тестовый аккаунт, используя один из приватных ключей, выведенных при запуске `yarn chain` (например, `0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80`).

## Тестирование

Для запуска unit‑тестов выполните:

```bash
yarn test
```

Все тесты находятся в `packages/hardhat/test/HashStorage.test.js` и покрывают успешные сценарии, проверки `require` и эмиссию событий.

## Использование

1. Откройте главную страницу приложения.
2. Подключите MetaMask к локальной сети Hardhat.
3. Выберите документ в блоке **Файл**. Приложение локально рассчитает `keccak256`‑хеш и не отправит содержимое файла в блокчейн.
4. Нажмите **Записать хеш** и подтвердите транзакцию в MetaMask.
5. Для проверки уже известного значения вставьте `bytes32`‑хеш в форму **Проверка по хешу** и нажмите **Проверить**.
6. В блоке статуса можно увидеть, найден ли хеш, кто его записал и когда.

## Структура проекта

- `packages/hardhat/contracts/` – исходный код смарт‑контракта `HashStorage`
- `packages/hardhat/deploy/` – скрипты деплоя
- `packages/hardhat/test/` – unit‑тесты
- `packages/nextjs/app/page.tsx` – пользовательский интерфейс для загрузки, записи и проверки хешей
- `packages/nextjs/hooks/` и `packages/nextjs/utils/` – web3‑хуки, уведомления и вспомогательная логика фронтенда
